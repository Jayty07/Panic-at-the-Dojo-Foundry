# Panic at the Dojo: Hero Builder

Step-by-step character creator for the *Panic at the Dojo: Patch'd Up* Foundry system, following the Hero Creation Checklist.

Open it from the **Hero Builder** button in the Actors sidebar, or from a Hero's sheet header (rebuilds that Hero).

Steps: Hero Type (Focused / Fused / Frantic, level, motive) → Archetypes (with the matching Ability shown) →
Stances (Style + Form with the full rulebook cards, Form name choice, Control Form option, live Stance preview) →
Build → Skills (trade one, two-word description) → Super Moves (level 2+) → Review → Create.

Enforced rules: distinct Styles and Forms; Focused Styles from one Archetype; Fused needs a Style from each Archetype;
Frantic takes one Style per Archetype; at most one Freestyle and its Banned Form is excluded; extra Stances,
Archetypes and Supers by level. Frantic Heroes receive every Style × Form pairing as a Stance.
The dice button rolls a random Hero.
